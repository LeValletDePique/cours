# NoteRow

Une note dans une liste : titre, matière, quand.

- `mc-note` : titre (`body` 500, tronqué), sous-ligne (point UE + matière), temps relatif en mono à droite (« 2 h », « hier », puis jj/mm).
- Note non classée : sous-ligne « Non classée · Classer » avec le lien d'action direct.
- La carte s'appelle « Reprendre » : on y va pour continuer, pas pour consulter un historique.
