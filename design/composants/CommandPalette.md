# CommandPalette

Recherche + actions au clavier, ouverte par `Ctrl K` ou `/`.

- Fermée : champ `mc-search` dans la barre du haut. Ouverte : `mc-palette` centrée, `shadow-pop`.
- Résultats groupés : Notes (plein texte, correspondance surlignée par `mark`), Matières, puis Actions avec leur raccourci.
- Flèches pour naviguer (`aria-selected`), Entrée pour ouvrir, Échap pour fermer.
