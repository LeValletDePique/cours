# EmptyState

Ce qu'on affiche quand une liste est vide : une phrase qui dit quoi faire, et le bouton pour le faire.

- `mc-empty` : bordure pointillée `line-strong`, texte `ink-muted`, un `mc-btn--sm`.
- La phrase explique le bénéfice (« il apparaîtra ici 7 jours avant »), pas l'absence (« Aucune échéance »).
- Jamais d'emoji ni d'illustration.
